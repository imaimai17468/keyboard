# 4. 基板

## 作り方

KiCad の Python API（`pcbnew`）で、配列の mm 座標から部品を置く基板をスクリプトで生成し、自動配線して、検査まで一続きで流せるようにします。手で部品を動かすと、配列を直すたびにやり直しになります。

1. 部品の形（フットプリント）を集める。スイッチとソケットは公開のライブラリ（perigoso/keyswitch-kicad-library など）、マイコンはメーカーのライブラリ（Seeed の OPL_Kicad_Library など）、ダイオードやコネクタは KiCad 標準のもの。**ライセンスを記録します**（CC-BY-SA なら改変して同じライセンスで公開できる）。
2. スクリプトで、スイッチ・ダイオード・マイコン・電池のコネクタを置き、ネット（どのパッドとどのパッドをつなぐか）を割り当てる。
3. 外形（角の丸みを含む）とネジ穴を描く。
4. 自動配線する（Freerouting など）。
5. DRC（設計ルールの検査）を通し、エラー 0・未配線 0 にする。
6. 工場用のデータ（ガーバー、ドリル、部品実装を使うなら BOM と CPL）を出す。
7. 配線した基板の画像と、基板の 3D の表示を作り、使う人に見せる。

KiCad の CLI（`kicad-cli`）で DRC とガーバーの出力ができます。Freerouting は Java が要ります。

## 部品の置き方

- ダイオードはスイッチの横の、穴とソケットのパッドを避けた位置に置きます。向きをそろえると、組み立てのときに目で確かめやすくなります。
- 部品実装を使うなら、部品は基板の片面（ふつうは表か裏の一方）にまとめると安くなります。

## マイコンの載せ方

- **アンテナの下と周りは、配線・ビア・銅箔の禁止範囲にします。** モジュールのデータシートや基板データからアンテナの位置を読み、両面とも禁止にします（実例では、アンテナ側の端から先 7 mm の帯の全高を禁止にした）。ケースが金属なら、アンテナの上は樹脂などの電波を通す素材にします。
- モジュールの裏に露出したパッドがあるときは、その下の表の面に配線を通しません（ショートする）。
- 横から半田付けしにくい位置のパッド（XIAO Plus の追加パッドや、モジュールの下に隠れる電池パッド）には、基板に穴を開けて裏からはんだを流せるようにします。穴を開けたら銅の残り幅を確かめます。使わないパッドには穴を開けず、裏の配線を通せるようにします。
- USB の口は、基板の外形のふちに合わせて置き、**ケースの外側の面から何 mm 奥になるか**をここで決めます（[case.md](case.md) の「外から挿す物の穴」）。

## 配線のこつ

- 配線の幅と間隔は、工場の最小値に余裕を持たせます（実例では 0.2 mm 以上・間隔 0.2 mm）。
- Freerouting は混んだ所で配線を細くすることがあるので、配線するときだけ間隔を少し広く（0.25 mm）して配線し、読み込んだあとで元に戻すと、DRC が通りやすくなります。
- 81 キーの 2 層基板で、自動配線は 7〜12 分ほどかかりました。

## ネジとケースの支え

- ネジの頭と、裏のネジ受けの柱が部品に当たらない位置を、スクリプトで探して決めます。決めた位置はファイル（JSON など）に書き出し、ケースの生成で読み込みます（同じ値を書き写さない）。
- ネジを通せない所は、ケースの底から柱で下から支えます。柱の上には絶縁のテープを貼ります。

## 1:1 印刷で実物に合わせる（関門）

DRC を通したら、基板を原寸で紙に印刷し、スイッチ・ソケット・マイコン・電池を実際に載せて確かめます。プリンタの拡大・縮小を切り、定規で 100 mm を測って原寸か確かめます。A3 が無ければ A4 に分けて印刷し、つなぎ合わせます。

確かめること:
- スイッチの足とソケットのパッドの位置
- マイコンの外形とパッドの位置、USB の口の向き
- 電池が置き場所に収まるか
- ネジの頭がスイッチやキーキャップに当たらないか

## 関門

DRC のエラー 0・未配線 0。1:1 印刷で実物と合っている。ネジの位置とマイコン・コネクタの位置が、ケースの生成に渡せる形で書き出されている。
