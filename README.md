# keyboard

自作キーボード制作用リポジトリ。

## 仕様

| パーツ | 仕様 | 状態 |
| --- | --- | --- |
| キーキャップ | 黒、刻印は彫りのみ（インク充填なし） | 決定 |
| 基板 | JLCPCB で色を試す（まずは白・黒） | 検討中 |
| ケース | シルバー | 決定 |

### 基板の色（JLCPCB）

JLCPCB で選べるソルダーマスクの色は、緑・青・赤・黒・白・紫・黄の7色。2層基板ならほとんどの場合、色による追加料金はない。発注前に見積もり画面で確認する。

シルク（文字）の色は基板の色で決まる。

| 基板の色 | シルクの色 |
| --- | --- |
| 白 | 黒 |
| 緑・青・赤・黄・黒 | 白 |

試す候補:

- [ ] 白（シルバーのケースに合わせて明るめ）
- [ ] 黒（黒のキーキャップに合わせて締める）
