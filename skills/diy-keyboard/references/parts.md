# 2. 部品を選ぶ

目指すのは「設計できる」基板ではなく、「実際に作れる安価な」基板です。

## ルール

- 工場の部品実装（JLCPCB の PCBA など）に載せる部品は、**Basic Parts** で、LCSC の在庫が豊富なものにします。Extended Parts は 1 種類ごとに追加料金がかかります。
- 手で半田付けする部品は、近くの店（日本なら秋月電子）や大きな通販で在庫があるものにします。
- **小さい部品（チップ抵抗、SOD-123・SOD-323・SOT-23 などのダイオードやトランジスタ）は手で付けさせず、部品実装に任せます。** 81 個の SOD-123 のダイオードを手で付けた実例では、時間がかかり、半田不足のキーが何個も出ました。
- 特殊な部品や調達しにくい部品は避け、部品の種類と点数を減らします。
- キーボード専用で、普通の電子部品店に無い部品（Choc のホットスワップソケット、XIAO などのマイコンモジュール、スイッチ）は例外です。使う前に、入手先が限られることを使う人に伝えて、了承をもらいます。

## 提案のしかた

部品を提案するときは、**その時点で調べた**次の値を表にして示します。覚えている値や古い記事の値を使いません。

| 項目 | 例 |
|---|---|
| 部品名と型番 | 1N4148W（SOD-123） |
| 買う店と部品番号 | LCSC C81598、秋月電子の通販コード、遊舎工房の商品ページ |
| Basic か Extended か（部品実装に載せるもの） | Basic |
| 在庫数 | 調べた日付と一緒に |
| 値段と必要数 | 予備を含めた数 |

キーボードの部品は、遊舎工房・Talp Keyboard（日本）、Kailh の公式ストア、AliExpress などで買えます。品切れが多いので、在庫と再入荷の予定を必ず見ます。

## 部品ごとの注意

- **スイッチ**: Choc V1 と V2 は軸の形が違い、キーキャップも違います。ソケットは V1・V2 共通のものがあります。必要数は、長いキーを複数のスイッチで支えるならその分を足し、予備も足します。
- **ホットスワップソケット**: スイッチの種類ごとに形が違います（Kailh の Choc 用は CPG135001S30 など）。基板の裏に付けるので、ケースの底との隙間を見込みます。
- **ダイオード**: 1 キーに 1 個。向き（col2row か row2col か）をファームと合わせます。部品実装に任せます。
- **マイコン**: 無線なら nRF52840 のモジュール。XIAO nRF52840 は充電回路を内蔵していて、電池を直接つなげます。XIAO の Plus 版は裏に追加のパッドがあり、ピンが増えますが、横から半田付けしにくい位置にあります（[pcb.md](pcb.md) の「マイコンの載せ方」）。
- **電池**: LiPo。保護回路の入ったもの。容量だけでなく厚さ・幅・長さでケースに入るかを決めます。コネクタの極性はメーカーによって逆のことがあるので、線の色ではなくテスターで確かめます。
- **分割のつなぎの部品**: 有線なら、ジャック（TRRS など）とケーブル。ジャックの寸法図でケースの穴を決めます（[case.md](case.md) の「外から挿す物の穴」）。無線なら、左右それぞれにマイコンと電池が要ります。
- **ネジ・インサート・ゴム足**: 規格（M2 など）、長さ、頭の径と高さを、ケースのめねじの深さや基板の厚さと突き合わせます。樹脂の部品に熱でインサートを入れられないときは、エポキシで接着します。

## 関門

部品表（型番・店・在庫・値段・数）が `docs/spec.md` の購入リストにあり、例外の部品に使う人の了承がある。
